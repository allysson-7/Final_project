## Random Fun Landing Page

A cool, random, and fun website landing page built with HTML, CSS, and JavaScript.

### Features
- Animated gradient background that shifts colors
- Floating particles for visual effect
- Randomizable content including title, facts, and colors
- Interactive button to trigger randomization
- Hover effects and animations

### Usage
1. Open `index.html` in your web browser.
2. Enjoy the random animations and content.
3. Click the "Click for Random Magic!" button to randomize the page elements.

### Files
- `index.html`: Main HTML structure
- `style.css`: CSS styles and animations
- `script.js`: JavaScript for interactivity and randomization

### Troubleshooting
- Ensure all files are in the same directory.
- If animations don't work, check browser compatibility (works best in modern browsers).
- No external dependencies required.
